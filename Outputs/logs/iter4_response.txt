### Reflexion & Step-Back Analysis (Iteration 4)
In Iteration 3, our regularized HistGradientBoosting model achieved a solid validation accuracy of 72.4%, precision of 0.679, and recall of 0.561 (F1: 0.614). While this showed good balance, our step-back analysis of the theoretical market microstructure model—specifically Kyle/Amihud-type frameworks linking order flow to price impact—reveals that we can extract much stronger linear and non-linear signals. 

Notice the exact mathematical identities in the dataset:
- `Return_Skewness == NOF_Skewness`
- `Return_Kurtosis == NOF_Kurtosis`
This structural relationship confirms that return distribution higher moments are direct linear reflections of net order flow distributions. Furthermore, `Return_Variance` and `NOF_Variance` are extremely stable across trading days, meaning variance itself carries little discriminatory power on its own, but its interaction with net order flow (e.g., flow relative to baseline volatility) is critical.

**Adaptations for the Current Iteration:**
1. **Enhanced Microstructure Features**:
   - **Order Flow Z-Score / Sharpe**: $\text{Mean\_NetOrderFlow} / \sqrt{\text{NOF\_Variance}}$ to measure directional pressure normalized by intraday dispersion.
   - **Cumulative Price Impact**: Ratio of `Price_Change` to `Mean_NetOrderFlow`, capturing instantaneous liquidity depth ($\lambda$).
   - **Tail Asymmetry Interaction**: $\text{Mean\_NetOrderFlow} \times \text{Return\_Skewness}$ to capture days where heavy-tailed order flow skew aligns with directional volume.
2. **Robust Classification Architecture**: 
   - We will utilize an ensemble combining **HistGradientBoostingClassifier** (with strict depth constraints to prevent overfitting) and an **L2-regularized Logistic Regression / Ridge Classifier** or a finely tuned **Random Forest** to capture both linear price-impact boundaries and non-linear regime shifts.
   - We will also optimize the probability decision threshold dynamically based on training distribution confidence scores.

import pandas as pd
import numpy as np
from sklearn.ensemble import HistGradientBoostingClassifier, RandomForestClassifier
from sklearn.linear_model import LogisticRegression
from sklearn.preprocessing import StandardScaler
from sklearn.pipeline import Pipeline
from sklearn.base import BaseEstimator, ClassifierMixin

def engineer_features(df: pd.DataFrame) -> pd.DataFrame:
    df_feat = df.copy()
    
    # Drop Day and Signal if present
    drop_cols = ['Day', 'Signal']
    feature_cols = [c for c in df_feat.columns if c not in drop_cols]
    
    X = df_feat[feature_cols].copy()
    
    # Theoretical Microstructure Feature Engineering
    # 1. Volatility estimates from variance
    X['NOF_Std'] = np.sqrt(np.maximum(X['NOF_Variance'], 1e-12))
    X['Return_Std'] = np.sqrt(np.maximum(X['Return_Variance'], 1e-12))
    
    # 2. Order Flow Signal-to-Noise Ratio (Flow Z-Score)
    X['NOF_SNR'] = X['Mean_NetOrderFlow'] / (X['NOF_Std'] + 1e-8)
    
    # 3. Price Impact Coefficient (Kyle's Lambda Proxy)
    X['Price_Impact_Lambda'] = X['Price_Change'] / (X['Mean_NetOrderFlow'].abs() + 1e-8)
    
    # 4. Return per unit risk
    X['Return_Sharpe'] = X['Daily_Return'] / (X['Return_Std'] + 1e-8)
    
    # 5. Tail Risk and Flow Skewness Interactions
    X['Flow_Skew_Interaction'] = X['Mean_NetOrderFlow'] * X['Return_Skewness']
    X['Flow_Kurt_Interaction'] = X['Mean_NetOrderFlow'] * X['Return_Kurtosis']
    X['Tail_Intensity'] = X['Return_Kurtosis'] * X['Return_Variance']
    
    return X

class CustomEnsembleClassifier(BaseEstimator, ClassifierMixin):
    def __init__(self):
        self.scaler = StandardScaler()
        self.gbc = HistGradientBoostingClassifier(
            max_iter=180,
            max_depth=3,
            learning_rate=0.03,
            l2_regularization=1.5,
            random_state=42
        )
        self.lr = LogisticRegression(C=0.5, penalty='l2', random_state=42)
        
    def fit(self, X, y):
        X_scaled = self.scaler.fit_transform(X)
        self.gbc.fit(X_scaled, y)
        self.lr.fit(X_scaled, y)
        return self
        
    def predict_proba(self, X):
        X_scaled = self.scaler.transform(X)
        p_gbc = self.gbc.predict_proba(X_scaled)
        p_lr = self.lr.predict_proba(X_scaled)
        # Ensemble average of probabilities
        return 0.7 * p_gbc + 0.3 * p_lr

# Global container for trained model
model_pipeline = None

def train_pred(df: pd.DataFrame) -> pd.DataFrame:
    global model_pipeline
    
    X_train = engineer_features(df)
    y_train = df['Signal'].astype(int)
    
    model_pipeline = CustomEnsembleClassifier()
    model_pipeline.fit(X_train, y_train)
    
    # Find optimal threshold on training probabilities
    train_probs = model_pipeline.predict_proba(X_train)[:, 1]
    
    # Target positive rate in training is ~39.5%
    target_pos_rate = y_train.mean()
    sorted_probs = np.sort(train_probs)
    threshold_idx = int(len(sorted_probs) * (1 - target_pos_rate))
    optimal_threshold = sorted_probs[max(0, min(threshold_idx, len(sorted_probs)-1))]
    # Clamp threshold to reasonable bounds
    optimal_threshold = np.clip(optimal_threshold, 0.35, 0.45)
    
    model_pipeline.threshold_ = optimal_threshold
    
    train_preds = (train_probs >= optimal_threshold).astype(int)
    return pd.DataFrame({'Signal': train_preds}, index=df.index)

def test_pred(df: pd.DataFrame) -> pd.DataFrame:
    global model_pipeline
    
    X_test = engineer_features(df)
    test_probs = model_pipeline.predict_proba(X_test)[:, 1]
    
    threshold = getattr(model_pipeline, 'threshold_', 0.40)
    test_preds = (test_probs >= threshold).astype(int)
    
    return pd.DataFrame({'Signal': test_preds}, index=df.index)
